# MARKET NOTE

티스토리 투자 블로그 스킨 `v1.5.1`

## 구성

- `skin.html`: 티스토리 치환자가 포함된 메인 템플릿
- `style.css`: 반응형 디자인과 게시글 본문 스타일
- `index.xml`: 스킨 정보, 홈 커버, 포인트 색상과 본문 너비 옵션
- `images/script.js`: 모바일 메뉴, 검색, 링크 복사, 표 스크롤, 자동 목차와 읽기 진행률 기능
- `preview` 파일: 스킨 미리보기 이미지

## 설치

1. 압축을 풀어 `skin.html`, `style.css`, `index.xml`과 `images` 폴더가 같은 최상위에 있는지 확인합니다.
2. 티스토리 관리자 → 꾸미기 → 스킨 변경 → 스킨 등록으로 이동합니다.
3. 최상위의 `skin.html`, `style.css`, `index.xml`, `preview` 파일을 선택합니다.
4. `images` 폴더 안의 `script.js`도 함께 선택해 업로드합니다.
5. 저장 후 스킨 보관함에서 **Market Note**를 적용합니다.

## 권장 설정

- 꾸미기 → 홈 설정: **커버 사용**
- 꾸미기 → 모바일: 티스토리 모바일웹 자동 연결을 **사용하지 않습니다**로 설정
- 스킨 편집 → 홈 커버: **시장 브리핑 히어로** 1개, **주요 글 카드** 6개
- 콘텐츠 → 설정: 글 목록 8개
- 대표 이미지 비율: 16:10 또는 4:3
- 댓글과 방명록의 비로그인 작성 허용 여부는 티스토리 관리자 설정을 따릅니다. 스킨은 해당 설정과 로그인 상태에 맞는 입력 폼을 자동 표시합니다.
- 댓글 영역은 게시물 하단에 기본으로 펼쳐집니다.

## 글 작성 팁

- 제목 2는 본문의 큰 소제목으로 자동 디자인됩니다.
- 제목 2와 제목 3이 두 개 이상이면 상세 화면 사이드바에 리포트 목차가 자동 생성됩니다.
- 본문 분량에 따른 예상 읽기 시간과 상단 읽기 진행률이 자동 표시됩니다.
- 표는 모바일에서 좌우 스크롤이 적용됩니다.
- 티스토리 에디터로 넣은 이미지, 인용문, 코드 블록에 대응합니다.
- JCOS `MASTER_AI_DAILY_v1.0.1`의 공통 리포트 스타일을 기본으로 지원합니다. `ai-daily-post` 마크업은 게시물별 CSS 없이도 히어로, 목차, 요약 카드, 강조 박스, 표, 코드와 액션 목록이 자동 적용됩니다.
- JCOS `MASTER_VSCODE_BEGINNER_GUIDE_v2.3.3`의 초보자 가이드 스타일을 기본으로 지원합니다. `jcos-vscode-guide` 마크업은 860px 읽기 영역과 전용 히어로, 안내·경고 박스, 코드 블록, 공식 자료 스타일이 자동 적용되며 제목 2의 네이비 언더라인은 스킨이 담당합니다.
- JCOS `MASTER_STOCK_DAILY_v1.0.0_TISTORY_BODY`의 Market Note 상속 계약을 지원합니다. `mn-report` 마크업은 시장 요약·경고 박스, 방향 색상, 넓은 표와 지표 차트의 모바일 스크롤이 자동 적용됩니다.
- 공개 글에는 개인의 보유 금액이나 계좌 정보가 포함되지 않았는지 다시 확인하세요.
